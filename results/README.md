# Results

All artefacts in this directory are generated by `python summarize.py` and are
committed to the repository so that the report can be rebuilt without a GPU.

| File | Content |
|---|---|
| `runs.csv` | one row per finished run: configuration, parameter count, best epoch, validation and test metrics |
| `per_class.csv` | one row per run × class: precision, recall, F1 and support on the test split |
| `agg.csv` | mean and standard deviation per variant across seeds |
| `summary.md` | markdown tables per ablation part |
| `tables.tex` | the same tables in LaTeX (booktabs) |
| `gesture_durations.csv` | duration of every contiguous gesture event in the processed recordings |
| `gesture_duration_summary.csv` | per-class gesture durations (mean / median / max) |
| `figures/` | PNG figures used by the report |

Metric definitions:

- `test_weighted_f1` — weighted F1 over all 18 classes (the paper's metric).
- `test_macro_f1` — macro F1 over all 18 classes, Null included.
- `test_gesture_macro_f1` — macro F1 over the 17 gestures, Null excluded.
- `test_accuracy` — window-level accuracy.

Test predictions are sample-wise (window stride 1): every sample of the four
test recordings is classified by the window that ends at that sample.
